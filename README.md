# Bash Questionnaire Project

This is a command-line interactive questionnaire script built with Bash as part of freeCodeCamp's Relational Database / Bash training track.

## Features
- Interactive user input handling using `read`.
- Variable creation, formatting, and string interpolation.
- Specialized shell formatting using `echo -e` and escape characters like `\n` for custom spacing.
- Sequential script execution tracking user details (`NAME`, `LOCATION`, `WEBSITE`).
